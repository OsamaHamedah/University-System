# University System
Spring Boot project with Student and Teacher CRUD (Task 5).

## Setup
1. Install PostgreSQL and create a database named `student`.
2. In `src/main/resources/application.properties`, set `spring.datasource.password` to your local PostgreSQL password.
3. Run `UniversitySystemApplication`.
4. API base paths: `/api/v1/student` and `/api/v1/teacher` (port 8080).
